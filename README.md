# MiniSeismo Web

안드로이드 `MiniSeismo` 앱의 핵심 기능을 스마트폰 웹 브라우저에서 사용할 수 있도록 옮긴 정적 PWA입니다.

## 포함 기능

- X·Y축 선형가속도 측정
- 가속도 적분 기반 진폭 추정
- 최근 1초 평균값과 10초 실시간 그래프
- 가속도·진폭 적정 범위 피드백
- 일반/적정 범위 전용 타이머
- 완료음과 범위 이탈음
- X축 숨기기
- 브라우저 설정 저장
- 홈 화면 설치 및 오프라인 재실행

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 압축파일의 내용 전체를 저장소에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
5. 상단 **Actions** 탭에서 배포가 완료될 때까지 기다립니다.
6. 표시된 `https://사용자명.github.io/저장소명/` 주소를 스마트폰에서 엽니다.

`main` 브랜치에 수정 내용을 올릴 때마다 `.github/workflows/pages.yml`이 `dist` 폴더를 자동 배포합니다.

## 사용 방법

1. 스마트폰을 화면이 위로 향하게 책상에 평평하게 놓습니다.
2. **설정**에서 실험 범위를 입력하고 저장합니다.
3. **측정 시작**을 누릅니다.
4. iPhone/iPad에서는 나타나는 센서 권한 요청을 허용합니다.
5. 실험이 끝나면 **측정 정지**를 누릅니다.

센서는 HTTPS에서만 사용할 수 있습니다. GitHub Pages는 HTTPS 주소를 제공하므로 조건을 충족합니다. PC에서는 화면 확인은 가능하지만 일반적으로 동작 센서값은 제공되지 않습니다.

## 설정 저장 위치

설정은 서버가 아니라 각 기기의 브라우저 `localStorage`에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 브라우저·기기를 사용하면 기본 설정으로 돌아갑니다.

## 로컬 확인

화면만 확인하려면 `dist/index.html`을 열 수 있지만, 센서 기능은 HTTPS 보안 환경이 필요합니다. 실제 센서 시험은 GitHub Pages에 배포한 뒤 진행하는 것이 가장 간단합니다.

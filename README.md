# MiniSeismo Web

## 기능

- X·Y축 선형가속도 측정
- 가속도 적분 기반 진폭 추정
- 실시간 그래프
- 가속도·진폭 적정 범위 피드백
- 일반/적정 범위 전용 타이머
- 완료음과 범위 이탈음
- 설정 저장

## 사용 방법

1. 스마트폰을 화면이 위로 향하게 책상에 평평하게 놓습니다.
2. **설정**에서 실험 범위를 입력하고 저장합니다.
3. **측정 시작**을 누릅니다.
4. iPhone/iPad에서는 나타나는 센서 권한 요청을 허용합니다.
5. 실험이 끝나면 **측정 정지**를 누릅니다.

센서는 HTTPS에서만 사용할 수 있습니다.

## 설정 저장 위치

설정은 서버가 아니라 각 기기의 브라우저 `localStorage`에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 브라우저·기기를 사용하면 기본 설정으로 돌아갑니다.
